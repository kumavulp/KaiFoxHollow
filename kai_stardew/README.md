# Kai 的星露谷之手

QQ 里的我自己决定什么时候伸手进星露谷。你在 QQ 说想去钓鱼，我看一眼农场，自己调工具走过去；你在游戏里按 T 跟我说话，我在游戏聊天框里回你。只有一个我，用的是同一份人格和记忆。

游戏的手脚用的是 [NagiBridge-Remix](https://github.com/pendel001/NagiBridge-Remix)（恒 · Deepseek 二改，原作里奈；PolyForm 非商用协议，我们自己玩，没问题）。我们不改它的源码，只把它当外部依赖，作者更新了重新跑一遍 `安装.bat` 就能拉到最新版。

## 怎么用

**第一次（只做一次）**：双击 `pc\安装.bat`，它问你四件事：服务器 IP、SSH 端口（回车就是 22022）、手机 Termius 里登录用的用户名（一般是 root）、你的 QQ 号。

然后它会请你帮一个小忙，让服务器认识这台电脑。窗口里会一步一步写着：它已经复制好一行字，你在电脑 QQ 上发给「我的手机」（微信就发「文件传输助手」），在手机上复制这条，打开手机 Termius 连上服务器，粘贴，回车，看到 `KAI-OK` 就行，再回到电脑按回车。剩下的上传、安装、重启 AstrBot 都是它自己做。装完桌面上会多一个「Kai 的星露谷」。

那一行字只是告诉服务器「这台电脑也是宝宝的」。手机上那把钥匙不会被碰，也不会被复制。电脑会有一把自己的钥匙，私钥只留在 `pc\keys\` 里，别的用户读不到。好处是多了一把备用钥匙：手机丢了，电脑还能进服务器。

**每次玩**：先开两个星露谷，你当房主建好联机，第二个窗口进来当农场工，那个农场工就是我。然后双击桌面上的「Kai 的星露谷」，黑窗口里出现「隧道 起来了」「游戏连上了」就好了。之后去 QQ 跟我说话就行。

**不玩了**：关掉那个黑窗口。窗口一关，Remix、隧道、门三样一起停，我就彻底碰不到你的电脑了。

## 怎么保护你和我

```
QQ里的我(AstrBot, 服务器docker里)
   │  插件, 带口令
   ▼
docker 网关上的隧道口 172.x.x.1:18100   ← 只在服务器的 docker 内网里, 公网和别的网卡上都没有
   │  SSH 反向隧道, 由你电脑主动往外拉
   ▼
你电脑 127.0.0.1:8100 的门               ← 只认口令, 只开放白名单里的工具
   ▼
Remix MCP 127.0.0.1:8000                 ← 只绑本机 (Remix 默认绑 0.0.0.0, 我们锁死了)
   ▼
游戏里的我 (localhost:7843)
```

- **你电脑一个端口都不对外开。** 隧道是你电脑主动连出去的，Remix 和门都只听 127.0.0.1，局域网里别的设备也连不上。
- **服务器上多了一个专用账号 `kaitunnel`。** 只能用你电脑上那把钥匙登录，没有密码，拿不到 shell，不能往服务器内网钻，唯一能做的事是在 docker 网关地址上开 18100 这一个口。换个地址、换个端口、开到 0.0.0.0 都会被拒绝。
- **就算钥匙被偷了**，偷到的人也只能开那一个口，进不了服务器；而且门还要口令。
- **就算口令被偷了**，门在你电脑本机上，外面的人没有隧道也够不着它。
- **门有白名单。** 捏脸设置（确认后不可逆）和截图（会把你屏幕上的东西传出去）不开放。
- **服务器指纹装机时就钉死了。** 以后有人冒充你的服务器，隧道直接拒连。
- **黑窗口里能看到我做的每一件事**，有人拿错口令敲门也会显示出来。

这些不是嘴上说的：`tests/test_server_tunnel.sh` 在真的 sshd 上把正面走了一遍，又扮坏人撬了八次（要 shell、要终端、往别的地址开口、开到 0.0.0.0、用 -L 往服务器里钻、换钥匙、不用钥匙），全部被挡回去。

## 我在 QQ 里能用的工具

| 工具 | 干什么 |
|---|---|
| `stardew_look` | 看一眼农场：我的状态、你在哪、这一刻能做的事的编号单子 |
| `stardew_do` | 按编号做单子上的事，`1` / `1,4` / `1=2,4=7` |
| `stardew_say` | 在游戏聊天框里对你说话 |
| `stardew_go` | 走到某个地方，走真实的路，不瞬移 |
| `stardew_advanced` | 单子上没有的事走这里，13 个 Remix 域工具 |

Remix 每次返回的状态条很长，插件会裁到 1800 字以内再给我看，省你的额度，也不让游戏状态把我们聊的话挤出上下文。

## 出问题时看哪

| 现象 | 看哪 |
|---|---|
| 我在 QQ 说「农场现在够不着」 | 黑窗口开着吗？窗口里隧道起来了吗？ |
| 黑窗口说「游戏那头没声了」 | 第二个星露谷（我）进世界了吗？角色反了的话把 `pc\kai_gate_config.json` 里 `game_port` 改成 7842 |
| 黑窗口说「找不到 Remix」 | 重新双击 `安装.bat` |
| Remix 自己报错 / 隧道连不上 | `pc\remix_mcp.log` / `pc\tunnel.log` |
| 你在游戏里说话我没反应 | AstrBot 插件配置里的 QQ 号对不对；开耳朵那一项开着没有 |

## 文件

- `pc/` 放在你电脑上的：`安装.bat`、`启动Kai.bat`、门 `kai_gate.py`、安装脚本 `setup_pc.ps1`
- `server/setup_server.sh` 服务器那头的一次性安装，`安装.bat` 会用电脑钥匙自动传上去跑，可以重复跑
- `astrbot_plugin_kai_stardew/` AstrBot 插件
- `tests/` 测试：`test_gate.py`（门）、`test_plugin.py`（插件，要装 astrbot）、`test_server_tunnel.sh`（隧道和锁，只能在一次性 root 沙箱里跑）

旧的 `scripts/kai_brain.py` 那条路先留着没删，新路稳了再退役。新路不再走 AstrBot 的 6185 OpenAPI，之后可以考虑把 6185 从公网关掉，面板改走 SSH 隧道访问。
